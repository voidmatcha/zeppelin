# Angular notebook baseline

The `angular-2026-09-15` files record ten cold and ten warm runs of the
ZEPPELIN-6668 notebook route benchmark. The JSON metadata identifies the exact
Zeppelin commit, fixture hash, browser, machine, build command and measured
entry bundles. Treat the measurements as a machine-specific comparison point,
not a general performance guarantee.
